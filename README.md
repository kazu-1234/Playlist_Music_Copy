# Playlist_Music_Copy (プレイリスト音楽コピー)

`.m3u` および `.m3u8` 形式のプレイリストファイルを読み込み、リストされている音楽ファイルを指定したフォルダに一括コピーするツールです。

## 機能
- **GUI操作**: わかりやすいGUIで操作できます。
- **対応形式**: `.m3u`, `.m3u8` ファイルに対応。
- **重複回避**: コピー先に同名ファイルがある場合、自動的に連番を付与して保存します（上書きしません）。
- **進捗表示**: プログレスバーでコピーの状況を確認できます。
- **ログ表示**: ファイルごとの処理結果（成功、スキップ、リネーム）をログで確認できます。

## 使い方
1. アプリケーション (`プレイリスト_音楽_コピー__v2.0.5.exe`) を起動します。
2. 「ファイルを選択」ボタンを押し、コピー元のプレイリストファイル (`.m3u` / `.m3u8`) を選択します。
3. 「フォルダを選択」ボタンを押し、音楽ファイルの保存先フォルダを選択します。
4. 「コピーを開始」ボタンを押すと、処理が始まります。
